# 🎬 Netflix Clone

Bu proje **HTML ve CSS kullanılarak geliştirilmiş bir Netflix ana sayfa klonudur.**
Netflix’in modern arayüz tasarımından esinlenerek hazırlanmış olup kullanıcı dostu ve responsive bir yapı sunar.

## 🚀 Proje Hakkında

Netflix Clone projesi, popüler film ve dizi platformu olan Netflix’in ana sayfa tasarımını yeniden oluşturmak amacıyla geliştirilmiştir.
Projede modern web tasarım teknikleri kullanılarak **mobil, tablet ve masaüstü cihazlara uyumlu (responsive)** bir yapı oluşturulmuştur.

## 💻 Projeyi Çalıştırma

Projeyi bilgisayarında çalıştırmak için:

1. Repoyu klonla

```bash
git clone https://github.com/rozerinzor/netflix-clone.git
```

2. Proje klasörüne gir

```bash
cd netflix-clone
```

3. `index.html` dosyasını tarayıcıda aç.
